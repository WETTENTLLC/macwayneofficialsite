# Mac Wayne Audio Player

## File Structure
- **Main index.html**: Root directory
- **Audio Player JS**: `js/new-audio-player.js`
- **Audio Fix Script**: `js/audio-fix.js`
- **Audio Player Init**: `js/audio-player-init.js`
- **Audio Player CSS**: `styles/audio-player.css`
- **Full Music Player**: `music-player.html`

## Audio Files
All audio files are located in:
- **Full Tracks**: `public/audio/Blind and Battered [Explicit]/`
- **Sample Tracks**: `public/audio/Blind and Battered [Explicit]/samples/`

## Features
- 30-second previews until purchase
- Individual track purchases ($1.99)
- Full album purchase ($9.99)
- PayPal integration
- Purchase tracking in localStorage

## Testing
