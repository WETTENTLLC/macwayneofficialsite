🎵 Mac Wayne Quick Debug

Quick Test

Debug Instructions

  1. Open macwayneofficial.com
  2. Press F12 to open Developer Tools
  3. Go to Console tab
  4. Look for messages starting with "[PLAYER]"
  5. Check for any red error messages

What to Look For

✅ Good signs:

  • "[PLAYER] renderPlaylist: Started. Number of tracks: 20"
  • "[PLAYER] fetchTracks: Tracks mapped: 20 tracks"
  • No red errors in console

❌ Problem signs:

  • Any red JavaScript errors
  • "Playlist element not found!"
  • "Number of tracks: 0"
  • PayPal-related errors

Common Fixes

⚠️ If no tracks show:

  • Hard refresh the page (Ctrl+F5)
  • Check if JavaScript is enabled
  • Clear browser cache

⚠️ If buy buttons don't work:

  • Check PayPal SDK is loaded
  • Look for modal-related errors
  • Try clicking without ad blockers
